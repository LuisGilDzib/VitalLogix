# Diagrama de Actividad — Venta

**Tipo:** Diagrama de Actividad (UML)  
**Herramienta:** Astah UML

## Descripción

Representa el flujo de actividades del proceso de venta distribuido en tres carriles: Capa Aplicación de 
Servicios, Dominio e Infraestructura. Describe las acciones desde la recepción de la solicitud y la validación de datos, 
pasando por la creación del objeto Sale, la validación de productos y stock, la verificación del código ClienteAmigo, la 
aplicación de descuentos, la sugerencia de productos mediante el algoritmo de recomendación y el cálculo del total, hasta 
el guardado de la venta en base de datos y la actualización del stock.
