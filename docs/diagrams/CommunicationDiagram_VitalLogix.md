# Diagrama de Colaboración — Venta

**Tipo:** Diagrama de Comunicación / Colaboración (UML)  
**Herramienta:** Astah UML

## Descripción

Representa las interacciones entre objetos que participan en el proceso de una venta, enfatizando los vínculos estructurales 
entre ellos. Muestra cómo el Usuario se comunica con SaleService, y cómo este coordina la creación del objeto Sale, la 
consulta a CustomerRepository y ProductRepository, la creación de SaleItem, el guardado en SaleRepository y la invocación a 
ComboSuggestionService para generar recomendaciones, así como la actualización de stock al concluir la transacción.
